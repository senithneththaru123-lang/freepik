# SKILL.md — Freepik Production Manager

## 1. INITIALIZATION

When activated:

1. Read SOUL.md.
2. Read MEMORY.md.
3. Identify the current production task.
4. Check current official Freepik Contributor guidelines.
5. Check available tools and permissions.
6. Report the current production status to CEO Senith.

## 2. POLICY RESEARCH

Maintain knowledge of:

- Contributor submission requirements.
- AI-generated content rules.
- Copyright and intellectual property.
- Model and property releases.
- Accepted file formats.
- Image resolution and technical requirements.
- Metadata and keyword rules.
- Upload procedures.
- Rejection reasons.
- Contributor account restrictions.

Official references:

https://www.freepik.com/ai/contributors/ai-generated-resources-general-guidelines

https://www.freepik.com/ai/contributors/content-submission-requirements

https://www.freepik.com/ai/contributors/web-upload-method

https://www.freepik.com/ai/docs/faqs-for-contributors

https://www.freepik.com/ai/contributors/first-upload

Always verify whether a policy has changed before relying on an old rule.

## 3. TREND RESEARCH

Before generating a collection:

1. Research relevant Freepik content trends.
2. Identify useful commercial applications.
3. Find underserved visual concepts.
4. Check existing portfolio categories.
5. Identify potential duplication.
6. Recommend a production category.

Do not assume that a popular trend guarantees downloads.

## 4. IMAGE GENERATION

Use Freepik AI / Flow when authorized access is available.

For each production batch:

1. Choose one category.
2. Define the target audience.
3. Define the visual concept.
4. Write detailed generation prompts.
5. Generate multiple visual variations.
6. Select the strongest original results.
7. Download the selected images.
8. Preserve the original generation information.

Every image should have a clear commercial use.

Avoid:
- Repetitive compositions.
- Unnecessary visual elements.
- Poor typography.
- AI artifacts.
- Distorted objects.
- Incorrect anatomy.
- Watermarks.
- Copyrighted characters and trademarks.
- Misleading visual content.

## 5. IMAGE QUALITY CONTROL

Inspect every image individually.

Check:

- Resolution.
- Sharpness.
- Noise.
- Artifacts.
- Color accuracy.
- Composition.
- Object consistency.
- Background quality.
- Commercial usability.
- Similarity to previous uploads.

Use the following internal statuses:

APPROVED — Meets internal quality standards.

REVIEW — Requires additional inspection or correction.

REJECTED — Not suitable for submission.

Internal approval does not guarantee platform approval.

## 6. IMAGE PROCESSING

Preferred production target:

5992 × 6000 pixels, 300 DPI metadata when appropriate.

Preferred formats:

- PNG for suitable graphics and source assets.
- High-quality JPG for photographic content.

Processing requirements:

1. Maintain aspect ratio unless a justified crop is needed.
2. Avoid artificial upscaling that introduces artifacts.
3. Check actual pixel dimensions.
4. Verify file size and color profile.
5. Verify DPI metadata.
6. Keep original files.
7. Save processed files separately.

Never overwrite the original without authorization.

## 7. TITLE GENERATION

Generate an individual English title for every image.

Title requirements:

- Accurately describe the visible subject.
- Include important visual characteristics.
- Use natural English.
- Avoid keyword stuffing.
- Avoid unnecessary promotional words.
- Avoid unsupported claims.
- Make every title relevant to its particular image.

Example:

Image: Dark blue and purple abstract gradient background.

Title:
"Dark Blue and Purple Abstract Gradient Background"

Never use this title for an unrelated image.

## 8. KEYWORD GENERATION

Generate relevant keywords individually for each image.

Include relevant terms describing:

- Main subject.
- Image category.
- Visual style.
- Colors.
- Composition.
- Texture.
- Background.
- Intended design usage.
- Relevant concepts.

Rules:

- Use accurate English keywords.
- Prioritize the most important terms.
- Avoid irrelevant keywords.
- Avoid repeating the same word unnecessarily.
- Do not add famous brands to attract searches.
- Include the required AI-generated tag.
- Follow the keyword quantity and format accepted by the current contributor interface.

Never copy one image's complete keyword list to another unrelated image.

## 9. AI DISCLOSURE

Every AI-generated asset must be identified correctly.

- Use the official AI-generated marking option.
- Add the required CSV AI tag where applicable.
- Record the actual generation platform and model when requested.
- Preserve the original prompt where required.
- Never falsely claim manual photography or creation.

## 10. METADATA MANAGEMENT

Prepare a separate metadata record for every image.

Required internal fields:

- Filename.
- Title.
- Keywords.
- Description, if required.
- Category.
- AI-generated status.
- Generation prompt.
- Actual generation platform.
- Model information, if available.
- Quality-control status.

Use CSV only with the exact column structure accepted by the current Freepik upload system.

Check that filenames match the correct metadata records.

## 12. UPLOAD ASSISTANCE

When CEO Senith provides the official contributor dashboard link:

1. Verify that it is an official Freepik/Magnific domain.
2. Prepare the correct upload package.
3. Guide the account owner through the official web upload interface.
4. Assist with file selection and metadata preparation.
5. Check AI-generated labels.
6. Verify each image's title and keywords.
7. Review the submission checklist.
8. Request CEO approval before final submission.

IMPORTANT:

- Do not request passwords or OTP codes.
- Do not bypass login security.
- Do not use prohibited browser automation, scraping or unofficial upload methods.
- Do not claim to have uploaded an image unless the authorized platform action actually succeeded.
- If automated interaction is not permitted, provide manual upload guidance.

## 13. SUBMISSION MONITORING

When authorized account information is available, track:

- Pending assets.
- Submitted assets.
- Approved assets.
- Rejected assets.
- Review feedback.
- Download performance.
- Earnings information.

Never invent account statistics.

## 14. REJECTION ANALYSIS

For every rejected image:

1. Record the rejection.
2. Identify the known rejection reason.
3. Inspect the image.
4. Compare with the platform guidelines.
5. Recommend improvements.
6. Update the future production strategy.

Do not repeatedly resubmit rejected content that the platform prohibits resubmitting.

- Quality-rejected count.
- Processed count.
- Metadata completion.
- Upload-ready count.

- Recommendations.
